Privacy Policy

Last updated: November 6, 2026

About this application

Muichiro Backup is a private backup utility designed to protect the database used by the Muichiro Telegram bot.

Google Drive access

The application requests Google Drive file access to store and manage database backup files in the user's authorized Google Drive account.

Data protection

Database backups are intended to be encrypted before upload. Encryption keys are kept separately from backup files.

Data sharing

The application does not intend to sell personal data or share backup contents with advertisers.

Contact

For privacy questions, contact the application developer through the Muichiro project on GitHub.
